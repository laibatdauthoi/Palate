# Palate

Palate is a media game where users upload media, push it into matches, and use APT to Buff the side they think should win.

Shelby is used only for uploading, storing, retrieving, and displaying user uploaded media.

The current MVP uses Aptos smart contracts to handle media registry, push, Buff, match settlement, rewards, protocol config, and user history.

Rialo may be integrated later for automation or future execution logic.
