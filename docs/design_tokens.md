# Design Tokens

## Brand Direction

Palate uses a dark premium interface with pink as the dominant accent family.

Pink must feel mature, luxurious, and intense.

Do not use cheap or candy-like pink.

## Gradient Direction

Use restrained premium gradients.

Examples:
gradient_primary = linear-gradient(135deg, #E84C9A 0%, #B64DFF 100%)
gradient_surface = linear-gradient(180deg, rgba(255,255,255,0.04) 0%, rgba(255,255,255,0.01) 100%)
gradient_hero = radial-gradient(circle at top, rgba(232,76,154,0.18), transparent 40%)

Do not use multicolor rainbow gradients.

## Typography

Use a modern clean sans serif.

Recommended direction:
Inter
Manrope
Sora

Headlines should feel bold and premium.

body_font_weight_regular = 400
body_font_weight_medium = 500
heading_font_weight_semibold = 600
heading_font_weight_bold = 700

## Radius

Use moderate radius.

radius_small = 10px
radius_medium = 16px
radius_large = 22px
radius_pill = 999px

Do not make the UI overly rounded or toy-like.

## Shadows

Use deep but controlled shadows.

shadow_card = 0 12px 30px rgba(0,0,0,0.28)
shadow_hover = 0 18px 45px rgba(0,0,0,0.36)
shadow_glow = 0 0 32px rgba(232,76,154,0.16)

## Borders And Surfaces

Cards should use subtle borders and layered surfaces.

Cards should feel elevated but not glassy to the point of losing readability.

Use transparency carefully.

## Motion

transition_fast = 160ms
transition_medium = 240ms
transition_slow = 360ms

easing_primary = cubic-bezier(0.22, 1, 0.36, 1)

Use motion for:
hover lift
panel fade
match reveal
button press
page transition

Do not use excessive playful motion.

## Buttons

Primary button:
pink dominant
high contrast
premium glow
strong readable text

Secondary button:
dark surface
subtle border
pink hover feedback

Danger button:
red pink toned
clear warning feel

## Cards

Cards should have:
dark premium surface
subtle border
soft highlight
slight hover lift
controlled glow on focus

## UI Constraints

No bright white backgrounds.

No pastel candy palette.

No overloaded neon.

No meme style UI.

No childish sticker style.

No cheap exchange dashboard look.

## Overall Goal

The UI should look expensive, sharp, modern, and immersive.

Pink is the signature, but the interface must remain dark, elegant, and cool.
