# Palate UI Spec

## UI Direction

Palate should feel like a premium GameFi product.

The UI should feel dynamic, powerful, elegant, and slightly dramatic.

The product should not look cute, candy-like, childish, or overly playful.

The core visual direction is:
luxury
bold
futuristic
competitive
stylish
high-end
dark with pink dominance

The UI should feel premium and intense, not noisy and not cheap.

## Core Mood

The mood should be:
cool
confident
sharp
cinematic
slightly aggressive
modern
immersive

The UI should suggest that Palate is a serious taste game with money involved.

## Color Feeling

Pink is the main color family, but the pink must be mature and luxurious.

Do not use bright candy pink, bubblegum pink, or overly saturated girly pink.

Pink should be used in a darker, richer, more premium way.

Good direction:
deep rose
dark magenta
muted hot pink
raspberry pink
pink glow on dark background

The pink should be supported by dark backgrounds and restrained neutral tones.

## Visual Style

The interface should look like a modern GameFi or premium digital arena product, but cleaner and more elegant.

Use:
dark backgrounds
large hero sections
strong contrast
soft glow accents
premium cards
high depth
subtle gradients
layered panels
slight glass or translucent effects if tasteful

Do not use:
rainbow gradients
too many neon colors
cute stickers
playful cartoon visuals
overloaded shadows
cheap crypto dashboard style

## Motion Direction

The UI must feel alive.

Use motion for:
page transitions
hover states
card focus
match reveal
button feedback
loading states
success states

Motion should feel:
smooth
confident
snappy
premium
intentional

Do not use excessive bouncing, spinning, or playful motion.

Animations should feel cinematic and controlled.

## Main Pages

The frontend should include these main pages:

Home
My Media
Upload
Waiting Pushes
Active Matches
Judge
Profile
Claims

## Home Page

The Home page should immediately communicate:
Palate is a taste based competitive media game.

The hero area should feel bold and premium.

It should include:
headline
short product explanation
primary actions
visual highlights
featured match style preview

Primary actions:
Upload Media
Create Push
Find Match

## My Media Page

This page shows the user's registered media.

Show media in premium cards.

Each card should show:
preview
title
category
status
available action

Status can include:
idle
waiting
active
settled

Actions depend on status.

Idle media can be pushed.

Waiting media shows waiting state.

Active media shows current match state.

Settled media shows result.

## Upload Page

The Upload page should feel simple and focused.

Flow:
select file
preview file
enter title
select category
upload to Shelby
register on chain

The upload process should clearly show progress and stage:
uploading to Shelby
registering on chain
completed

## Waiting Pushes Page

This page shows media waiting for challengers.

Each waiting push card should show:
media preview
owner or shortened address
push amount
time created
action to challenge

The page should feel competitive.

## Active Matches Page

This page shows active matches at a high level.

Each match card should show:
media A preview
media B preview
time remaining
category
basic action or detail link

Do not show:
live score
love pool
leading side
win probability

## Judge Page

This is one of the most important pages.

The Judge page should feel dramatic and immersive.

Flow:
user clicks Find Match
match is assigned
two media are shown side by side
user chooses a side
user enters love amount
user confirms

There should also be a clear Skip action with visible penalty warning.

The two media should be the visual focus of the page.

The page should feel like a decision screen.

## Profile Page

Show user statistics in a premium and readable way.

Display:
push_count
push_win_count
push_loss_count
push_profit
love_count
love_win_count
love_loss_count
love_profit
total_pushed
total_loved
claimable_amount
push_win_rate
love_win_rate

The stats should be easy to scan and visually strong.

## Claims Page

The Claims page should show all available rewards.

Separate:
push claims
love claims

Each claim item should clearly show:
match reference
claimable amount
claim type
claim action

## Components

The frontend should include these reusable UI elements:

navigation_bar
page_header
stat_card
media_card
match_card
waiting_push_card
judge_panel
action_button
status_badge
claim_card
wallet_panel
empty_state
loading_state
error_state

## Component Style

Cards should feel deep, premium, and slightly dramatic.

Buttons should feel bold and expensive.

Badges should be clean and sharp.

Panels should not feel too rounded or toy-like.

## Layout

The layout should use a dark background and centered content width.

Spacing should be clean and controlled.

The UI should breathe.

Do not cram too many panels into one screen.

## Responsive Behavior

The UI should work on desktop first, but should remain usable on tablet and mobile.

The Judge page and media cards are especially important to adapt carefully on smaller screens.

## Final Design Goal

The Palate UI should feel like a premium, dynamic, taste-driven GameFi product with a dark luxurious atmosphere and a refined pink signature.

It should look cool, powerful, and expensive.

It must not look childish, overly cute, or visually noisy.
